# Трекер стримов

Программа для Windows, которая живёт в трее и:

- **сама считает стримы.** Каждые 10 минут проверяет, идёт ли эфир на вашем Twitch-канале, и засчитывает стрим. Прошлые стримы подтягивает из статистики Twitch;
- **показывает план на месяц:** сколько стримов набрано и сколько осталось до конца месяца;
- **напоминает про отчёт** в выбранные дни (по умолчанию 13-го и 29-го, до конца дня);
- **собирает отчёт:** делает скриншоты «Отчёта о трансляции» Twitch по каждому стриму за период и пишет список «дата длительность» в `отчёт.txt`. Кнопка «Скриншоты в буфер» копирует все скриншоты: Ctrl+V в Telegram вставит их альбомом.

## Установка

1. Скачайте **[StreamTracker.exe](StreamTracker.exe)** (кнопка «Download raw file» справа вверху на странице файла).
2. Положите файл в постоянное место, например в `Документы\Трекер стримов`. Не запускайте его из «Загрузок»
   или прямо из архива: автозапуск и ярлык будут указывать на этот файл.
3. Запустите `StreamTracker.exe`. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите
   **Подробнее → Выполнить в любом случае**. Это предупреждение появляется для любых программ без платной цифровой подписи.
4. Откроется окно настройки:
   - **Аккаунт Twitch:** нажмите «Войти в Twitch» и войдите в открывшемся окне браузера. Трекер сам заметит вход, закроет окно и будет следить за каналом этого аккаунта — ссылку на канал вводить не нужно;
   - **План:** сколько стримов нужно в месяц, в какие дни сдавать отчёт (сдать нужно до конца дня, 23:59);
   - галочки «Запускать вместе с Windows» и «Ярлык на рабочем столе».
5. Нажмите «Готово». Значок трекера появится в трее рядом с часами.

Всё это можно поменять позже через шестерёнку в главном окне.

## Что нужно знать

- **Windows 10 или 11.** Ничего дополнительно ставить не нужно: .NET Framework 4.8 уже есть в системе.
- **Браузер.** Для скриншотов статистики нужен браузер на Chromium. Трекер возьмёт браузер по умолчанию, если это Chrome,
  Edge, Яндекс Браузер, Brave или Vivaldi. Иначе он возьмёт Microsoft Edge, который есть в любой Windows 10/11.
- **Вход в Twitch** хранится в отдельном профиле браузера. Ваш обычный браузер и его вход трекер не трогает, пароль он не видит.
  Войти нужно один раз на компьютер: Twitch держит сессию месяцами, а если она закончится, трекер сам предложит войти снова.
- **Канал — это аккаунт, под которым вы вошли.** Сменить его можно кнопкой «Сменить» в настройках.
- Стримы засчитываются, пока компьютер включён и трекер запущен. Пропущенные трекер подтянет из статистики Twitch.

## Где лежат данные

В папке программы остаётся только `StreamTracker.exe`, а всё остальное хранится в стандартных местах Windows:

| Что | Где |
|---|---|
| Настройки и список стримов | `%APPDATA%\StreamTracker` |
| Профиль браузера со входом в Twitch | `%LOCALAPPDATA%\StreamTracker` |
| Отчёты (скриншоты и `отчёт.txt`) | `Документы\Трекер стримов\Отчёты` |

Поэтому `StreamTracker.exe` можно переносить или обновлять, и данные при этом не теряются.

**Как удалить полностью:** в главном окне откройте настройки (шестерёнка) и снимите галочки автозапуска и ярлыка,
затем закройте трекер через значок в трее → «Выход» и удалите `StreamTracker.exe` и обе папки `StreamTracker`
(вставьте `%APPDATA%` и `%LOCALAPPDATA%` в адресную строку Проводника). Отчёты в «Документах» удаляйте по желанию.

## Сборка из исходников

Исходники лежат в папке [`src`](src). Сборка использует компилятор C#, встроенный в Windows, поэтому Visual Studio не нужна:

```powershell
powershell -ExecutionPolicy Bypass -File src\build.ps1
```

Готовый `StreamTracker.exe` появится в папке `src`.
